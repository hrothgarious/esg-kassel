# ESG Kassel · Semesterplan Print Studio

Prototyp: erzeugt den Semesterplan WiSe 2026/27 als Plakat (A3), Handzettel (A4)
und DL-Flyer und exportiert druckfertige, ebenenbenannte SVGs für Illustrator.

Läuft komplett im Browser – kein Server, keine Datenübertragung. Änderungen an
den Terminen werden nur lokal im Browser gespeichert.

Schriften: Inter, Caveat, Amatic SC, Reenie Beanie – SIL Open Font License 1.1,
siehe `fonts/OFL.txt`.
